## What is Lanzate UI?

A React component library built on ui-sdk and Tailwind CSS. It's not installed as a dependency: components live directly in your repo, so you can change them freely.

## Philosophy

Copy, paste, and own. No unnecessary abstractions, no vendor lock-in. Each component is your code from day one.
