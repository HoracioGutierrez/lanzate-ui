# Text

<Lead>Typography with 8 sizes, 9 intent colors, heading and overline presets, and weight, font and line-height props. It renders a paragraph by default; pick another element, like a heading, with `render`.</Lead>

## Variants and type props

`variant` sets a role preset; `weight`, `font`, `leading` and `color` adjust it. Reach for `className` only for layout, like margins.

<Demo name="text-variants" />

## HTML element

`render` sets the element; `size` and `color` stay independent of it, so the document outline and the visual scale don't have to match.

## Usage

```tsx
import { Text } from "@/components/ui/text"

// Default paragraph (size="md")
<Text>Standard body text.</Text>

// h1 with the display size
<Text render={<h1 />} size="display">
  The interface that takes off
</Text>

// Caption with an intent color
<Text render={<span />} size="xs" color="muted">
  Last updated: 2 min ago
</Text>

// Section label
<Text variant="overline" size="xs">Installation</Text>

// Section title
<Text render={<h2 />} variant="heading" size="display">
  One command and you're in orbit
</Text>

// Error message
<Text size="sm" color="error">
  This field is required.
</Text>
```
