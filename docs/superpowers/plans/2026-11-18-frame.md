# Frame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `frame` registry component: an industrial box with four corner marks, an optional header (back button, free title content, three-dot menu) and optional user-toggled collapse.

**Architecture:** Composable parts in `src/components/ui/frame/`, following `floating-toolbar`. `Frame` provides a context (`size`, `collapsible`); when collapsible, the root is ui-sdk `Collapsible`, `FrameTitle` is the `CollapsibleTrigger` and `FrameContent` the `CollapsiblePanel`. `FrameMenu` wraps ui-sdk `Menu` + `MenuTrigger` + `MenuContent`; menu classes are duplicated from `floating-toolbar.variants.ts`, not imported.

**Tech Stack:** React 19, Next.js, Tailwind v4, `@ui-sdk/react` (`collapsible`, `menu`, `agent`), `lucide-react`, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-18-frame-design.md`

## Global Constraints

- Repo rules in `AGENTS.md` and `src/components/ui/AGENTS.md`: one component per file, types only in `frame.types.ts`, class maps in `frame.variants.ts` with `satisfies Record<Union, string>`, named exports, `cn` from `@/lib/cn`, no literal design values, `"use client"` only where needed.
- Import ui-sdk parts from their entry (`@ui-sdk/react/collapsible`, `@ui-sdk/react/menu`). Never import from `floating-toolbar`.
- Square corners (no `rounded-*` on the frame), `border-border`, `bg-card`, corner marks `border-primary` on all four corners.
- Every control has an accessible name. `FrameBack` default label `"Back"`; `FrameMenu` requires `label`.
- Collapse animation respects `prefers-reduced-motion`.

## Review Focus

- A collapsible frame with no `FrameHeader`/`FrameTitle`: content must still render (open by default), nothing crashes. → test in Task 1.
- Pressing `FrameBack` or `FrameMenu` in a collapsible header must not toggle the content. → test in Task 2.
- Controlled `open` without `onOpenChange` stays put; `onOpenChange` reports the user's toggle. → test in Task 1.
- A long title truncates instead of pushing back/menu out of the header. → `min-w-0 truncate` on the title label; checked in browser in Task 4.
- Non-collapsible `FrameTitle` must not render a button (no false affordance). → test in Task 1.

**Interfaces (produces):**
- `type FrameSize = "sm" | "md" | "lg"`
- `FrameProps`: `div` props minus `children`/`className` + `{ className?, children?, size?: FrameSize (default "md"), collapsible?: boolean, open?: boolean, defaultOpen?: boolean (default true), onOpenChange?: (open: boolean) => void }`

- `FrameTitleProps`: `{ className?, children? }` (button props when collapsible are forwarded)
- `FrameContentProps`: `div` props + `{ className? }`
- `FrameContext` (`frame.constants.ts`): `{ size: FrameSize; collapsible: boolean }`, default `{ size: "md", collapsible: false }`
- `data-slot`s: `frame`, `frame-header`, `frame-title`, `frame-content`; four `aria-hidden` `span[data-slot="frame-corner"]`

**Variants (`frame.variants.ts`), values from the spec, Tailwind scale only:**
- `frameClasses`: `group/frame relative flex flex-col border border-border bg-card text-card-foreground`
- `frameCornerClasses` per corner (`top-start`, `top-end`, `bottom-start`, `bottom-end`) with `-top-px`/`-bottom-px`, `-start-px`/`-end-px`, matching `border-t/b` + `border-s/e`, `border-primary`, `pointer-events-none absolute z-10`
- `frameCornerSizeClasses`: sm `size-2`, md `size-3`, lg `size-4`
- `frameContentPaddingClasses`: sm `p-3`, md `p-4`, lg `p-6 md:p-10`
- `frameHeaderHeightClasses`: sm `min-h-9`, md `min-h-11`, lg `min-h-14`
- `frameHeaderClasses`: `flex items-center gap-1 border-b border-border px-1` + `group-data-closed/frame:border-b-0`
- `frameTitleClasses`: `flex min-w-0 flex-1 items-center gap-2 self-stretch px-2 text-start font-mono text-xs tracking-wide uppercase`; trigger adds `outline-none focus-visible:inset-ring focus-visible:inset-ring-ring cursor-pointer` and a chevron (`ChevronDown`, `aria-hidden`, `ms-auto text-muted-foreground transition-transform data-open:rotate-180 motion-reduce:transition-none`)
- `frameContentPanelClasses`: `h-(--collapsible-panel-height) overflow-hidden transition-[height] duration-200 ease-out data-starting-style:h-0 data-ending-style:h-0 motion-reduce:transition-none`
